Model Router — the intelligence tier

Inspects queries in <3ms using deterministic regex heuristics (heuristics.py), evaluates custom conditional rule DAGs, hard-prunes context windows, and scores candidate models across 5 Pareto dimensions with automated 80%/95%/100% budget intervention guards.

Terminal Agent & Sandbox — the execution tier

Generates formal Task Contracts (TaskContractGenerator), builds compact repository context with AST symbol ranking (DeterministicRanker), modifies code using 12 typed tools, and isolates processes with psutil tree termination.

AgentBench — the calibration tier

Runs polyglot test harnesses (Python pytest and Node.js 22 node --test), scores agents across 5 weighted dimensions ($S \in [0, 100]$), ingests live GitHub PRs, and acts as an automated CI/CD gatekeeper before merge.

IndependentVerifier & Checkpoints — the safety tier

Prevents conversational hallucinations by demanding objective test passes and diff verification. Checkpoint manifests enable instant, zero-risk rollback to baseline states on unrecoverable failures.

Terminal Agent

Autonomous software engineering agent built on a verify-first architectural paradigm.

Python 3.10+ MIT License Local-First Ollama Ready Verify-First SQLite Persistence
GitHub Repo → Issue Tracker →
01

Verify-First Engine

Structural separation between agent hypotheses and verification. IndependentVerifier runs test suites in isolated sandboxes and confirms 0 failures before task completion.

02

Deterministic AST Ranker

Scores repository files using AST symbol definitions (def, class, function, interface, struct), path matches (10x weight), and keyword frequency without vector DB overhead.

03

Process-Tree Sandbox

Dual execution modes (LocalSandbox and DockerSandbox) with psutil recursive process-tree termination, preventing zombie child workers on timeouts.

04

12 Core Typed Tools

Complete filesystem and git toolset: read_file, write_file, edit_file, list_files, search_files, run_command, run_tests, git_status, git_diff, git_log, create_checkpoint, restore_checkpoint.

05

SecretGuard & Security

5-tier command policy (safe, write, destructive, network, privileged) paired with Shannon entropy secret redaction and blocklists for .env and keys.

06

State & Snapshot Rollback

Atomic checkpoint snapshots (.terminal_agent/checkpoints/) and SQLite session persistence (terminal_agent.db) with instant rollback via CLI (terminal-agent rollback).

from terminal_agent.agent.loop import AgentLoop
from terminal_agent.config import TerminalAgentConfig
from terminal_agent.verifier.engine import IndependentVerifier
from terminal_agent.providers.ollama_provider import OllamaProvider

cfg = TerminalAgentConfig(
    provider="ollama",
    model="qwen2.5-coder:1.5b",
    sandbox="local",
    max_retries=3,
    auto_rollback_on_failure=True,
)

# Run autonomous verify-first coding session
loop = AgentLoop(config=cfg, provider=OllamaProvider(model=cfg.model))
session = loop.run(task_description="Fix JWT expiry leeway in src/auth/jwt.py")

if session.status == "VERIFIED":
    print("Task completed and verified by IndependentVerifier!")
    print("Modified files:", session.diff_summary)
from model_router.router.engine import RoutingEngine
from model_router.analyzer.heuristics import analyze_request

# Sub-3ms prompt classification & Pareto candidate scoring
analysis = analyze_request("Debug distributed async queue deadlock in Celery")
engine = RoutingEngine()

decision = engine.route(
    prompt="Debug distributed async queue deadlock in Celery",
    policy="balanced",          # quality | cost | speed | balanced
    analysis=analysis
)

print(f"Selected: {decision.selected_model.id} (Score: {decision.score:.1f})")
print(f"Why this model? {decision.explanation}")
print(f"Disqualified candidates: {decision.rejection_reasons}")
